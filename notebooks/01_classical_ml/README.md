# Módulo 01: Machine Learning Estadístico & Optimización Convexa

Este módulo aborda el paso de la optimización combinatoria a la continua, y cómo los fundamentos estadísticos previenen el sobreajuste.

## Notebooks Planificados
* `01_gradient_descent_and_linear_models.ipynb`: Regresión lineal y logística from scratch, paisajes de pérdida convexos y tasas de aprendizaje.
* `02_regularization_geometry.ipynb`: Geometría de $L_1$ (Lasso) vs $L_2$ (Ridge / Weight Decay).
* `03_decision_trees_to_xgboost.ipynb`: De particiones ortogonales a Gradient Boosted Decision Trees con derivadas de segundo orden (Taylor).
* `04_generalization_and_evaluation.ipynb`: Trade-off sesgo-varianza, teoría PAC y validación estadística rigurosa.
