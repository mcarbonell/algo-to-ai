# Módulo 04: La Revolución del Transformer y la Atención

Construcción completa de la arquitectura que domina la IA moderna: atención, embeddings rotatorios y decodificadores autoregresivos.

## Notebooks Planificados
* `01_attention_mechanics.ipynb`: Scaled Dot-Product y Multi-Head Attention from scratch con visualizaciones de similitud.
* `02_positional_encodings_rope.ipynb`: De embeddings sinusoidales a Rotary Position Embedding (RoPE) en el plano complejo.
* `03_nanogpt_from_scratch.ipynb`: Construcción integral de un LLM tipo GPT/LLaMA con tokenizador BPE y KV-Cache para generación rápida.
